Built for the room operator

Stop synchronizing five separate tools by hand.

A conference room often runs from a spreadsheet, timer, slide folder, speaker-name document and several displays. ShowSlate turns them into one cue state, while leaving cameras, audio and streaming in the tools already built for those jobs.

Conference Desk workflow

From show folder to a confirmed Program state

01

Import and match

Select a folder containing CSV/TSV and media. ShowSlate matches exact filenames, reports skipped rows and keeps the original files untouched.

02

Assign and preflight

Give each display a role and run Test outputs. A destination stays SYNCING until it confirms the expected Program revision.

03

Select NEXT, then GO

Selection never changes LIVE. GO updates the cue, timer, linked media and automatic speaker lower third as one transaction.

Before you download

Questions

What problem does it solve?

It replaces manual synchronization between a conference spreadsheet, speaker timer, media folder, lower-third notes and several room displays. One GO action applies the prepared cue state everywhere.

Can it import my Excel schedule?

Export the rundown sheet as CSV/TSV or paste its rows into the wizard. Direct XLSX parsing is intentionally not included in this beta.

Is it really free and offline?

Yes. The MIT License permits use, modification and redistribution. The core workflow needs no account or internet. Network views stay on the trusted production LAN.

Which file should I download?

Apple Silicon Mac users need the ARM64 DMG. Windows 10/11 x64 users should choose the Setup EXE. GitHub Source code archives are not installers.

Does it replace OBS, vMix or a video switcher?

No. ShowSlate does not switch cameras, mix audio or encode a stream. It coordinates conference timing, content, lower thirds and displays while those tools keep their existing jobs.

Is Stream Graphics certified with OBS or vMix?

No. Internal transparent rendering is tested, but external alpha capture depends on the other application's pipeline. Verify the exact workflow off-air before a live event.

Should I use ProTimer or ShowSlate Conference Desk?

Choose ProTimer for a fast countdown, OBS overlay, phone remote and simple rundown. Choose ShowSlate when the room also needs linked content, speaker lower thirds, LIVE/NEXT/GO and role-based outputs.

Language support

English by default. Serbian when you need it.

English and Serbian have full interface coverage. The other 35 language choices cover core operator controls and fall back to English for advanced areas. The exact policy is documented in Languages.
